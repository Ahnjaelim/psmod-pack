# Personal Mod Pack (Probably Stolen)

*Probably Stolen*용 개인 모드팩입니다. 여러 모드를 DLL 하나로 합쳐서 버전 관리할 대상이 하나뿐입니다.

현재 버전: **2.22.0**

## 구성

- **QoL Tweaks** (`PenLabelerAssist/`): 창작마당 모드 *Pen's QoL Tweaks* v1.1.5를 개인용으로 빌드할 수 있게 옮긴 사본입니다. 문자열은 영어로 번역했습니다.
  - 빠른 구매 / 판매 / 감정 / 추궁 단축키 (빠른 판매 = "물건 N개 판매" 버튼, 기본 Enter)
  - 도구 박스 선택 일괄 처리
  - 배터리 자동 교체
  - 수경재배 자동 재심기
  - 서류 자동 버리기
  - 창 따라가기 / 스냅
  - 화학 완성기 일괄 수량 슬라이더. 고른 수량이 출력 버튼을 눌러도 바뀌지 않습니다.
- **Better Keybinder** (`Merged/ComboKeyPresets.cs`)
  - 보관 코디네이터 프리셋과 공구함 슬롯 키에 Ctrl / Shift / Alt 조합을 쓸 수 있습니다.
  - 돋보기, 모든 창 닫기 단축키를 추가합니다 (기본 Ctrl+Shift+W, 옵션 > 키 설정).
  - 공구함 단축키나 돋보기 단축키로 집은 도구는 한 번 사용하면 바로 내려놓습니다.
  - 옵션 > 키 설정의 모든 단축키 옆에 [x] 버튼을 붙입니다. 누르면 단축키가 "없음"으로 비워지고, 적용을 눌러야 저장됩니다.
- **Better Butcher Machine** (`Merged/BetterButcherMachine.cs`): 자동 도축기 우리 탭에 "복합" 도태 모드를 추가합니다.
  - 나이 또는 무게 기준으로 도태합니다.
  - 번식용 개체는 남깁니다.
  - 과밀하면 가벼운 개체부터 줄입니다.
- **Better Scanner UI** (`Merged/BetterScannerUI.cs`): 워터 스캐너와 화학 스캐너의 성분 목록을 줄 단위로 다시 그립니다.
  - 한 줄은 성분명(왼쪽) | 액체 색 막대그래프(퍼센트를 막대 위에 겹쳐 표시) | 양(오른쪽, 흐리게)으로 되어 있습니다.
  - 양이 많은 성분부터 정렬합니다. 양은 uL / mL / L로 표시합니다.
  - 액체 이름이 "Translation Error 'liquid_...'"로 나오면 복구합니다. 스캐너뿐 아니라 모든 화면에 적용됩니다.
- **신문 확인 버튼** (`Merged/NewspaperConfirm.cs`): 신문에 확인 버튼을 붙입니다. 누르면 신문을 휴지통으로 옮기고 창을 닫습니다.
- **달력: 오늘의 이벤트** (`Merged/CalendarTodayTooltip.cs`)
  - 벽걸이 달력 화면에 오늘의 이벤트 목록을 표시합니다.
  - 달력 툴팁에 오늘의 이벤트를 종료일, 가격 영향과 함께 표시합니다.
- **유전자 등급** (`Merged/GeneGrades.cs`): 동물 툴팁의 유전자 능력치마다 S~F 등급을 붙입니다.
  - 발현값을 종 기본값과 비교해서 매깁니다. 낮을수록 좋은 능력치는 비율을 뒤집어서 계산합니다.
  - 기준: S +30% 이상, A +15% 이상, B +5% 이상, C ±5% 이내, D −5% 미만, F −15% 미만.
  - 유전자 스캐너를 켜면 대립유전자마다 따로 등급을 매겨 `A / S`처럼 표시합니다 (슬래시는 회색).
- **가치 블록** (`Merged/ValueTooltip.cs`): 아이템 툴팁의 가치 정보를 정리합니다. 각 줄 앞에 크레딧 아이콘이 붙습니다.
  - 현재가: 산 물건은 구매가 대비 `(+n 이득)` / `(−n 손해)`를 표시합니다. 남의 물건(내 소유가 아닌 물건)은 대신 기본가 대비 `(−n 저가)` / `(+n 고가)`를 표시합니다.
  - 칸당 가치: 추정 가치 ÷ 아이템이 차지하는 칸 수.
  - 구매가 (기본가): 흐리게 표시합니다. 구매 기록이 없으면 기본가만 표시합니다.
- **카테고리 박스** (`Merged/CategoryPills.cs`): 아이템 카테고리 태그를 좌우 여백이 같은 하이라이트 박스로 바꿉니다. 밀수품 박스는 빨간색입니다. 내 소유가 아닌 물건에는 노란 "남의 물건" 박스가 붙습니다.
- **감정 기본값/최저값 버튼** (`Merged/AppraisalPresets.cs`): 감정 서비스 입력 창의 가격 +/- 버튼 밑에 `기본 N` / `최저 N` 버튼을 붙입니다. 누르면 그 값이 입력 칸에 들어갑니다.
  - 의수 100 / 50, 립위치 150 / 40, 플라즈마 연료 300 / 90
- **감정 계산기** (`Merged/AppraisalCalculator.cs`): 감정 창 왼쪽에 세로형 상자를 바짝 붙이고(화면 밖으로 넘치면 오른쪽), `[카테고리]` 별로 체크박스를 한 줄에 하나씩, 가격 영향이 낮은 것부터 나열합니다. 직접 보고 판단한 상태를 체크하면 게임 계산식대로 값을 계산해서 입력 칸에 바로 넣습니다. 립위치 공장 항목에는 고품질/저품질 공장 번호를 같이 표시합니다. 상자 위에 마우스를 올려도 뒤에 있는 물건의 툴팁은 뜨지 않습니다.
  - 같은 줄의 항목(예: 금도금/탄소 복합재)은 하나만 고를 수 있습니다. 세트 보너스와 씰 조건은 자동으로 계산합니다.
  - 숨겨진 정답을 읽지 않습니다. 체크한 내용으로만 계산합니다.
- **라벨 가격 영향** (`Merged/LabelPriceEffect.cs`): 툴팁의 라벨 줄을 가격 영향에 따라 색칠하고 `(-10%)`처럼 퍼센트를 붙입니다.
  - 남의 물건: 가격을 올리는 라벨은 빨강, 내리는 라벨은 초록 (살 때 기준)
  - 내 물건: 가격을 올리는 라벨은 초록, 내리는 라벨은 빨강 (팔 때 기준)
- **우클릭 메뉴 유지** (`Merged/ContextMenuStay.cs`): 마우스가 열린 우클릭/정렬 메뉴 창 안에 있으면 메뉴가 닫히지 않게 합니다. 다른 모드(Smart Inventory Arrange 등)가 끼워 넣은 줄로 마우스를 옮겨도 메뉴가 사라지지 않습니다.
- **숙성기 일수** (`Merged/AgeWellTooltip.cs`): 숙성기 툴팁에 하루 숙성 일수(와인 자체 +1, 숙성기 1 + 품질%/125)와 다음 단계까지 필요한 품질을 표시합니다.
- **전체 선택** (`Merged/SelectAll.cs`): `Ctrl + A`(옵션에서 키 변경)를 누르면 마우스가 올라간 인벤토리의 아이템을 전부 다중 선택합니다. 드래그 박스 선택과 같은 조건(꺼낼 수 있고 고정되지 않은 아이템)이며, 선택 후 동작도 같습니다.
- **총기 크기** (`Merged/GunSizeTooltip.cs`): 총기와 총기 부품 툴팁에 크기(차지하는 칸 수)를 표시합니다. 총기는 총기 주문 조건이 보는 값입니다.
- **Ctrl + 클릭 선택** (`Merged/CtrlClickSelect.cs`): 윈도우 탐색기처럼 `Ctrl + 클릭`으로 아이템을 하나씩 다중 선택에 넣고 뺍니다(같은 인벤토리 안). 게임 기본 Ctrl + 클릭 빠른 이동은 막히며, 빠른 이동을 쓰려면 옵션에서 다른 키로 바꾸면 됩니다.
- **프린터 칩 표시** (`Merged/PrinterChipTooltip.cs`): 3D 프린터 툴팁에 꽂혀 있는 칩 이름(없으면 "없음")을 표시합니다.
- **블록 진행 막대** (`Merged/BlockProgressBar.cs`): 툴팁의 `[=====     ]` 진행 막대(기계 진행, 체력, 내구도 등 전부)를 밝은 칸/어두운 칸 블록 막대로 그립니다.
- **기계 진행 위치/남은 일수** (`Merged/MachineProgressMove.cs`): 작업 중인 진행형 기계(프린터, DNA 조작기, 수경재배기 등) 툴팁에서 진행 막대를 "진행 속도" 줄 바로 밑으로 옮기고, 현재 진행 속도 기준 완료까지 남은 일수(오늘 밤 완료 / 완료까지 N일)를 표시합니다. DNA 조작기는 "형질 추출 중" 상태와 성공 확률도 함께 옮깁니다.
- **모듈 실효치** (`Merged/ModuleRatioEffective.cs`): 모듈 효과 줄에 비율이 붙어 있으면(예: `성능: +1400% (비율 0.5)`) 뒤에 실제로 적용되는 값(`→ +700%`)을 붙입니다.
- **물 용량 쉼표** (`Merged/WaterVolumeCommas.cs`): 물/액체 용기 툴팁의 용량 숫자에 천 단위 쉼표를 찍습니다(`8,189 ml / 20,000 ml`).
- **Vanilla Gunsmith Extension** (`Merged/GunsmithExtension.cs`): 바닐라 그림만 써서 3D 프린터로 만들 수 있는 총기 부품과 프레임을 늘립니다. 부품 칩 16종(손잡이, 젤 그립, 개머리판, 짧은 개머리판, 내부 스프링, 탄약 표시기, 양각대, 고급 레이저, 보정기, 방아쇠 뭉치, 총열, 매치 총열, 고급 소음기, SMG 탄창 3종)과 리볼버/SMG/샷건 프레임 칩(금속 프린팅 + CNC 모듈 필요, 프레임에 총기 부품을 끼우면 완성)을 추가하고, 은퇴한 총기 장인이 확률로 팝니다. 아이템 ID는 `vge_` 접두사이며, 이 아이템이 든 세이브는 모드를 빼면 해당 아이템을 불러오지 못합니다.
- **방문 손님 달력** (`Merged/GunsmithCalendar.cs`): 정기 방문 손님(은퇴한 장인들, 공급업자, 발명가, 평판 퍽/시작 직업 손님 등 24종)을 지금 해금 상태 기준으로 큰 달력 날짜 칸 안쪽(이벤트 아래)에 배경 없이 글자로 표시합니다. 자리가 모자라면 "+N"으로 줄이고, 날짜 칸에 마우스를 올리면 그날 이벤트와 방문 손님 전체를 툴팁으로 보여줍니다. 벽 달력 화면/툴팁에는 오늘 방문 손님과 다음 총기 장인 방문일이 나옵니다.
- **모드 이름 번역** (`Merged/ModNameTranslate.cs`): 모드 메뉴에 중국어로 나오는 다른 모드 이름을 번역해 보여줍니다. Localization의 `modname_<모드ID>` 키를 쓰고, 없으면 "中文 / English" 이름에서 영어 부분만 씁니다. 메모리에서만 바꾸고 다른 모드 파일은 건드리지 않습니다.

## 번역

모드팩 문자열은 `Localization/en.csv`와 `Localization/ko.csv`에 있고, 기본값은 `PenLabelerAssist/Text.cs`에 있습니다.

한글 번역 모드 테이블에 액체 이름이 빠져 있어서 `ko.csv`에 한국어 액체 이름(`liquid_*`)도 넣었습니다.

## 빌드

프로젝트는 게임의 `Probably Stolen_Data/Managed` DLL을 참조합니다. 빌드 명령:

```
dotnet build -c Release
```

빌드하면 DLL, `manifest.xml`, `Localization/`이 `Mods/PersonalQoLTweaks/`로 복사됩니다. 게임이 실행 중이면 DLL이 잠겨 있으니 먼저 게임을 끄세요.

## 참고

- 모드 ID는 `personal-qol-tweak`입니다.
- 게임 로더는 DLL 하나당 `IMod`를 하나만 만듭니다. 진입점은 `PenLabelerAssistMod`이고, 합쳐진 모듈의 활성화/비활성화 처리를 여기서 호출합니다.
- `[HarmonyPatch]` 클래스는 로더의 `PatchAll`이 적용합니다.
- 게임 모드 검사기가 `reflection-external`을 거부하므로 `<Capabilities/>`는 비워 둡니다.
  - 람다를 넘긴 `AccessTools.FirstMethod`는 "computed type"으로 판정되어 모드팩 전체가 막힙니다.
  - 대신 `AccessTools.Method(typeof(X), "고정된 이름")`과 `Prepare()`를 함께 쓰세요 (`GeneGrades.AddStatLinePatch` 참고).
- 수정할 때마다 `manifest.xml`의 `<ModVersion>`을 올리세요.
